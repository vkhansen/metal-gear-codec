metal-gear-codec
================

A simple implementation of the Metal Gear Solid codec, in SVG and JS.

**Repo:** https://vkhansen.github.io/metal-gear-codec/

Codec face boxes are **140×180 px, 7:9 JPEG**. Crop portraits with `scripts/crop-codec-avatars.ps1`. Full steps: `avatars/RUNBOOK.md`.

Bake per-line codec voices with `scripts/bake_codec_audio.py` (xAI TTS, Big Boss = `leo`, Jeerasak = `rex`). Full steps: `audio/RUNBOOK.md`.

**DATA LINK (PDF):**

- [Karabeyoglu, Dyer, Stevens and Cantwell — *Modeling of N₂O Decomposition Events* (AIAA 2008-4933)](papers/AIAA-2008-4933-N2O-Decomposition-Events.pdf)
- [Scaled Composites — *Safety Guidelines for N₂O* (17 June 2009)](papers/N2O-Safety-Guidelines.pdf)
